# PiSentry

PiSentry is a Raspberry Pi 5 honeypot and intrusion tripwire built using OpenCanary.

## Current prototype

- Raspberry Pi 5
- OpenCanary
- Fake HTTP login page
- FTP honeypot
- Captures test intrusion events

## Future work

- Custom PiSentry skin
- Real-time alerts
- Persistent logging
- Dashboard
- Automated installation

For authorised testing and educational use only.
